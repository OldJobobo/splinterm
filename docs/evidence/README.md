# Retained validation evidence

This directory contains public fixtures and reproducibility records required by tests, documentation, or release verification. It is evidence, not an implementation roadmap or source of current product requirements.

Numeric identifiers and historical “Plan” wording inside captured records identify the work that originally produced the evidence. Current product authority lives in the PRD, status document, ADRs, and specialist documentation.

The evidence tree moved from `docs/plans/artifacts/` to `docs/evidence/artifacts/` after the public/private coordination split. Measured payloads and captured review records remain unchanged. Four checksum-covered README files had obsolete links to removed internal plans replaced with self-contained public wording; their README entries in the adjacent `SHA256SUMS` manifests were refreshed as part of that documented path correction.
