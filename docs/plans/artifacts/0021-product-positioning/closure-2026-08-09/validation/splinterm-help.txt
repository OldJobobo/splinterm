Splinterm terminal client

Usage: splinterm [OPTIONS] [COMMAND]

Commands:
  sessions         Choose a recent running logical Dojo or create a fresh terminal
  reopen           Reopen the most recently opened logical Dojo that is still running
  window           Render ordered snapshots of one explicitly selected terminal
  ping
  focus            Read only the keyboard-focused graphical Splint ID and current working directory
  reset            Stop the daemon, back up and clear every session, then restart cleanly
  list             List active Lairs without flooding the terminal with exited history
  authorization    Inspect effective authority or revoke ephemeral grants
  relay            Bridge private protocol bytes over non-terminal stdin/stdout
  remote           Inspect strictly parsed remote connection profiles without connecting
  config           Validate local client configuration without contacting the daemon
  keymap           Inspect built-in or effective client keymaps
  policy           Validate, inspect, or reload the local persistent policy
  audit            Inspect bounded in-memory daemon audit records
  subscribe        Stream bounded machine events as NDJSON
  topology         Inspect all reviewed topology metadata
  inspect          Inspect one Splint by stable identity
  new              Create a persistent Lair with one Dojo and live Splint
  launch           Create a fresh graphical Lair, or explicitly attach by Splint ID
  split            Split a target leaf and launch a new sibling
  close            Close an exited Splint leaf and collapse its parent branch
  ratio            Change the ratio of the selected Splint's parent branch
  new-dojo         Create a persistent Dojo with one live Splint
  close-dojo       Close a Dojo whose Splints have all exited
  rename-lair
  rename-dojo
  dojo-focus-hint  Set a persisted convenience hint without changing any client's actual focus
  rename-splint
  relaunch         Relaunch an exited Splint under a new process incarnation
  restore          Restore one exited Splint using its saved launch metadata
  restore-dojo     Restore every exited Splint in a saved Dojo
  restore-lair     Restore every exited Splint in a saved Lair
  snapshot         Show one live terminal snapshot (development mode only)
  scrollback       Read one bounded page of terminal history
  search           Search terminal history without echoing the query in machine output
  send             Send literal UTF-8 text to one live shell (development mode only)
  resize           Resize one live terminal (development mode only)
  kill             Kill one live process while retaining its Splint leaf
  help             Print this message or the help of the given subcommand(s)

Options:
      --output <OUTPUT>              Select human output or the supported JSON machine contract [possible values: human, json, ndjson]
      --schema-major <SCHEMA_MAJOR>  Select the public machine schema major
      --timeout-ms <TIMEOUT_MS>      Bound a machine request deadline in milliseconds
      --remote <PROFILE>             Bind this invocation to one configured remote daemon endpoint
  -h, --help                         Print help
  -V, --version                      Print version
