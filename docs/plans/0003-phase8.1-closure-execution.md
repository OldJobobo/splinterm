# Plan 0003: Phase 8.1 closure execution

- **Status:** Active
- **Parent:** [Plan 0002](0002-omarchy-terminal-mvp.md#phase-81-foot-visual-parity-and-graphical-scrollback-completion)
- **Reference:** Foot 1.27.0 commit `3c5b584b0eafa772eb4376fb6eaf6643399e190e`
- **Rule:** Phase 8.1 remains open until every exit gate below has evidence.

## Current baseline

Implemented and currently uncommitted:

- exact 95/95 printable-ASCII grayscale masks through isolated FreeType and the production cache;
- stable daemon-owned history generations and row IDs;
- protocol-v11 bounded, revision/generation/incarnation-bound history paging;
- row/byte-bounded client history cache and multi-page prefetch;
- exact-ID detached viewport anchoring;
- Foot-derived wheel accumulation using the active renderer cell height;
- release-mode `splinterm-test`, accepted manually for wheel responsiveness and deep-history paging; and
- opt-in content-free scroll timing through `SPLINTERM_SCROLL_TRACE=1`.

Known open gates:

- final composited Foot/Splinterm ARGB parity;
- complete face/size/scale matrix;
- four-sided padding, cell, cursor, and decoration geometry;
- every optimized renderer/cache path equivalence;
- detached-history status controls and page-boundary selection/reflow behavior;
- pinned CI provenance and reference-update policy;
- performance thresholds; and
- final Hyprland/Omarchy sign-off plus ADR 0004 closure.

## Execution policy

Each slice must:

1. preserve daemon ownership, authentication, scope checks, and all protocol bounds;
2. keep Foot as the observable authority unless ADR 0004 records a reviewed divergence;
3. avoid per-character offsets, best-fit image translation, broad tolerances, and silent reference regeneration;
4. include focused tests and update the relevant spike/ADR evidence;
5. pass `cargo fmt --all --check`, strict workspace Clippy, workspace tests, and `git diff --check`; and
6. remain independently reviewable before the next dependent slice starts.

## Slice 1 — A1 final composited buffer oracle

- **Status:** In progress
- **Current evidence:** default 95×1 geometry, origins, edge clearances, and
  ARGB bytes are exact. The former two-pixel `%`/`&` overhang mismatch was
  traced to Foot's right-to-left row composition and eliminated. Remaining
  work is fixture and parameter-matrix automation. See
  [`tools/foot-oracle/README.md`](../../tools/foot-oracle/README.md#final-buffer-oracle-in-progress).

### Foot capture

- Add a second disposable Foot patch that dumps the completed pre-submit render target without changing canonical Foot sources.
- Emit raw ARGB bytes plus JSON metadata: width, height, stride, format, scale, grid, cell metrics, four padding edges, cursor, fixture, frame ID, Foot/fcft/font provenance.
- Make capture deterministic and reject unexpected Foot commit or environment drift.

### Splinterm capture

- Add a final-buffer exporter using the production `TerminalSnapshot` → `SnapshotFrame` → `paint_snapshot` path.
- Parameterize fixture, face, logical size, scale, grid, padding, cursor, palette, and cache state.
- Emit the same raw-byte and metadata contract as Foot.

### Comparator

- Compare declared origins directly; never translate images.
- Report exact mismatch count, maximum channel delta, mismatch bounds, per-cell counts, edge-clearance deltas, and first divergent cell.
- Produce machine-readable JSON plus PPM/PNG crops and heatmaps.
- Add parser/fuzz bounds and comparator self-tests.

### Fixtures

- printable ASCII row;
- leading/trailing spaces and punctuation;
- `iiii`, `WWWW`, `....`, `____`, `||||`;
- 80- and 240-column drift rows;
- edge cells, reverse, dim, cursor shapes, and conceal.

### Gate

Default regular ASCII has exact geometry, no drift/clipping, and zero unexplained ARGB mismatch. One command builds/captures/compares both implementations.

## Slice 7 — D2 reflow and cross-page selection

### Policy

- live resize follows reflow at bottom;
- detached resize anchors by row ID plus intra-row position;
- generation-changing reflow explicitly resets/remaps;
- selection endpoints use row IDs and columns;
- endpoint pages remain pinned until copy or explicit cancellation.

### Tests

- grow/shrink and soft-wrap reflow;
- wide cells;
- selection across three pages;
- output during selection;
- endpoint trim;
- clear, resync, alternate screen, detach, and reattach.

### Gate

No silent wrong-row selection or anchor survives incompatible generation changes; copy across loaded pages is deterministic and private.
