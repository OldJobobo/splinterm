# Splinter Display releases

These versions apply only to the font asset, independently of Splinterm application releases.

## v0.1

Initial original Heavy display face:

- 104 characters: printable ASCII, nonbreaking space, curly quotes, en/em dashes,
  ellipsis, and bullet.
- Approved Splinterm wordmark outlines, proportional letters, tabular lining
  figures, and 218 kerning pairs.
- TTF, CFF OTF, and WOFF2 exports with the repository's MIT license embedded.
- Editable outlines, reproducible builds, rendered proofs, and an interactive viewer.

One weight, unhinted; accented and non-Latin characters are not included.
