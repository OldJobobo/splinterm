# Terminal image test fixtures

Executable protocol and pixel-oracle inputs used by terminal and renderer tests.

- `protocol-fixtures/` contains bounded Sixel, Kitty, and iTerm2 command cases.
- `foot-sixel-oracle/` contains only the Foot framebuffer bytes and rendering metadata required for exact pixel comparisons.

These are source-owned test inputs, not benchmark results, host observations, graphical acceptance records, or planning artifacts.
